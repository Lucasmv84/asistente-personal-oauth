Política de privacidad

Última actualización: 27 de septiembre de 2026.

1. Alcance

Asistente Personal es una herramienta privada de uso individual. Esta política explica cómo utiliza la información obtenida mediante las APIs de Google.

2. Datos a los que accede

  • Gmail en modo de sólo lectura: metadatos y contenido de mensajes necesarios para elaborar resúmenes y detectar asuntos pendientes.
  • Google Calendar: eventos y datos de agenda necesarios para contrastar fechas y detectar conflictos.

La aplicación no solicita permisos para enviar o modificar Gmail ni para acceder a Google Drive.

3. Finalidad

Los datos se utilizan únicamente para prestar las funciones solicitadas por el titular: resúmenes de correo, identificación de acciones, consulta de agenda y detección de conflictos.

4. Almacenamiento y procesamiento

Las credenciales OAuth se almacenan localmente en el perfil privado de Hermes del titular. El historial y las notas generadas también se conservan localmente, salvo que el titular autorice expresamente otra acción.

El contenido necesario puede ser procesado por el proveedor de inteligencia artificial configurado para generar la respuesta solicitada. La aplicación no vende datos, no los utiliza para publicidad y no los comparte con terceros para fines ajenos a la función pedida por el titular.

5. Conservación y control

El titular puede eliminar sus datos locales y revocar el acceso desde la sección de conexiones de su Cuenta de Google. Al revocarse el acceso, la aplicación deja de poder consultar Gmail y Calendar.

6. Seguridad

Se solicitan únicamente los permisos necesarios. Las acciones externas —como enviar correos o modificar calendarios— requieren autorización específica y no están habilitadas por los permisos actuales.

7. Uso limitado de datos de Google

El uso de información recibida de las APIs de Google cumple con la Política de Datos de Usuario de los Servicios API de Google, incluidos sus requisitos de Uso Limitado.
